# Security

Jangan mengirim password atau secret melalui issue publik. Laporkan kerentanan secara privat kepada pemilik repository. Jangan memakai foto stok sebagai bukti identitas atau dokumentasi kegiatan aktual.

Konfigurasi autentikasi, batas upload, keterbatasan satu proses dan prosedur cadangan dijelaskan pada docs/DEVELOPMENT.md dan docs/DEPLOYMENT.md.
