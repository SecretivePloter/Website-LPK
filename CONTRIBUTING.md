# Kontribusi

Buat branch perubahan dan pull request. Gunakan identitas commit yang disetujui pemilik repository (Kresna untuk pekerjaan ini). Jangan menyimpan credential atau runtime-data ke Git.

Jalankan `npm ci`, `npm run check`, lalu `npm run test:integration`. Lampirkan screenshot desktop dan mobile ketika mengubah tampilan; dokumentasikan perbedaan dengan referensi. Ikuti AGENTS.md untuk konvensi teknis dan docs/DEVELOPMENT.md untuk struktur modul.
