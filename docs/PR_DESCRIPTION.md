Membangun website LPK Asahi Nusantara dari template cloner: beranda, profil, program, galeri, struktur organisasi dan halaman informasi legal. Foto sementara tersedia lokal dan dapat diganti lewat admin.

Admin menambahkan login server, unggah gambar tervalidasi, edit judul/alt/kategori/urutan, penggantian slot gambar dan penghapusan dari manifest. Media dan metadata disimpan pada disk persisten dengan penulisan atomik untuk satu proses Node.js. Dokumentasi mencakup pengembangan, API, penggunaan admin, deployment dan backup.

Validasi: lint, TypeScript, build produksi serta pengujian integrasi autentikasi dan lifecycle aset. Batas verifikasi visual tercantum pada docs/VALIDATION.md. Tidak ada deployment hosting. Foto stok dan halaman kebijakan yang belum memiliki sumber resmi harus ditinjau sebelum peluncuran.
